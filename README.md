# Tu Día Hábil .UY - tudiahabiluy.github.io

Calculadora de días hábiles en Uruguay con feriados 2026 y Ley 16.805.

## Qué incluye este ZIP

- `index.html` -> versión corregida con marca TU DÍA HÁBIL.UY (motor intacto, mismo cálculo que tenías)
- `banner.jpg` -> 1200x630 OG image para WhatsApp / Facebook / Twitter
- `og-image.jpg` -> copia del banner
- `favicon.ico` + `favicon-16x16.png`, `32x32`, `48x48`
- `apple-touch-icon.png` (180), `android-chrome-192/512`
- `logo-1024.png` -> master para Play Store, redes
- `site.webmanifest` -> PWA
- `robots.txt` + `sitemap.xml`
- `404.html` (redirección simple)

## Cómo subir a GitHub Pages

1. Descomprimí este ZIP
2. Copiá todo a la raíz de tu repo tudiahabiluy.github.io (reemplazá index.html y banner.jpg)
3. Commit & Push

Queda listo con el banner que te genera preview lindo en WhatsApp.
